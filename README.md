Casa Pablo - Vermut de Altura

Descripción:
Este proyecto es una página web de e-commerce desarrollada como parte de un curso de Front-End.
La página estará destinada a presentar y vender productos de Casa Pablo - Vermut de Altura.

La página está estructurada con HTML semántico y utiliza las etiquetas <header>, <nav>, <main> y <footer> para organizar el contenido.

El objetivo es aprender a crear la estructura básica de una página web y prepararla para futuras mejoras con CSS y JavaScript.

Formulario de contacto:

Se creó un formulario de contacto utilizando Formspree para recibir los datos enviados por los usuarios sin necesidad de configurar un servidor propio.

Configuración:
Se creó un formulario en Formspree y se utilizó la URL proporcionada en el atributo action del formulario.
El formulario utiliza el método POST y cada campo contiene un atributo name para identificar los datos enviados.
